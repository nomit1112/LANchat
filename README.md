## LAN Chat Application (Qt/C++)

## Description
This is a beginner-level LAN chat application created using Qt Widgets and C++.

The project was developed as part of a Software Engineer Intern assignment.

## Implemented Features
- Basic chat interface
- Send button functionality
- Local chat history saving
- Reload previous messages on startup
- Nearby users list UI
- Visibility toggle

## Technologies Used
- Qt 6
- C++
- Qt Widgets
- QFile / QTextStream

## Current Status
The UI and file persistence features are completed.

Basic nearby users interface is implemented.

Real peer-to-peer socket communication is still under development.

## Build Instructions
1. Open project in Qt Creator
2. Configure Desktop Kit
3. Click Run

- Real TCP messaging
